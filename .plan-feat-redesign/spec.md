# Goal Contract — 内容组织与交互范式重设计研究（redesign）

> 2026-09-12 | 用户指令: 不止动画层——内容组织结构与交互方式要重新想; 详细搜索最好的设计; 基于强依赖的 learncc; 产出要有点 prioritization

## Objective

产出「内容组织 + 交互方式」设计提案: 以 learncc 为强锚点（活体走查 + 源码级内容模型）, 外部最佳实践横评, 对照本站差距, 给出**按读者体验影响排好优先级**的重组方案（含取舍与代价）。

## Success Criteria

| # | 标准 | 验收 |
|---|---|---|
| SC-R1 | learncc 内容地图与交互物件清单（活体+源码双源, 证据到页面/选择器/file:line） | 两份研究底稿落盘 |

| SC-R4 | 不重复否决区（面板汇流等五项）与 D 线已完成结论; 引用需标注 | 提案含「既有结论引用表」 |

- 零依赖零构建红线（提案必须可在此约束内实现, 或显式声明做不到）

- 研究阶段只读, 不改 site/
- subagent 联网必须走 web-access skill（RULES.md）
