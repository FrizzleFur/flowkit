# SVG 页面生成规范

> 来源：linux.do 帖 1782304（sandun）开源的页面生成提示词，叠加本 skill 的工程化约束。
> 格式决策：整页 SVG（而非图片或 HTML）——可导入 Office 2016+ 完全可编辑、可无限放大、各设计软件通吃。

## 生成提示词模板

对每一页，组装以下指令（`{{PAGE_CONTENT}}` 填该页大纲内容与检索数据）：

```text
作为精通信息架构与 SVG 编码的专家，你的任务是将完整的文字内容转化为一张
高质量、结构化、具备高级感、简洁感和专业感的 SVG 演示文稿页面。

要求如下：
1. 画布: SVG viewBox 必须是 0 0 1280 720。
2. 内容页采用便当网格 (Bento Grid) 布局（规范见 bento-grid.md）。
3. 色板（全篇统一，不得发明新色）:
   背景 {{BG}} / 卡片底 {{CARD}} / 主色 {{PRIMARY}} /
   强调色 {{ACCENT}} / 正文 {{TEXT}} / 次要文字 {{MUTED}}
4. 字体: font-family="'PingFang SC','Microsoft YaHei','Noto Sans SC',sans-serif"
5. 禁止占位文本，所有内容来自: {{PAGE_CONTENT}}

请你根据以上要求输出这一页的完整 SVG 代码。
```

## 工程约束（每页生成时自检）

1. **文本防溢出**：卡片 rect 的宽高必须为内部文字预留 padding ≥ 20px；一行中文按 `字号 × 1.05 × 字数` 估宽，放不下就换行（`<tspan x dy>`）或缩字号，不硬塞
2. **标题层级**：页标题 36-44px / 卡片标题 22-26px / 正文 16-18px / 注释 12-14px
3. **语义分组**：每张卡片一个 `<g>`（含 rect + 标题 + 正文），页码/页眉放独立 `<g>`
4. **无外部依赖**：不引用外部图片/字体/CDATA 样式表；图标用简单 path 手绘或省略，保证拖入 PowerPoint 不丢资源
5. **数字排版**：关键数据用大号字 + 强调色（如 64px），单位用次要色小号字
6. **单文件自包含**：每页 SVG 可独立打开，文件头含 `<!-- page: NN | title: xxx -->` 注释便于批量处理

## preview.html 查看器（阶段 4 收尾产物）

极简实现要点：
- 内嵌读取所有 `NN-*.svg`（`<object data="01-cover.svg">` 或 fetch 注入）
- 左右方向键 / 空格 / 点击按钮翻页；右下角显示 `N / 总数`
- 深色背景居中显示，SVG 按宽 100% 缩放（`viewBox` 自适应）
- 单文件、无依赖，直接 `open preview.html` 即用
